# apps/api

- `src/main.ts` - bootstrap: load env, create app, serve Swagger UI at `/docs`, listen.
- `src/app.factory.ts` - `createApp` (loads features, builds Nest app, shutdown hooks) and `buildOpenApiDocument`; used by main, tests, export.
- `src/app.module.ts` - root module; composes database, health and dynamically loaded feature modules. Must not import features statically.
- `src/features/feature-loader.ts` - discovers feature packages on disk by manifest and imports enabled ones dynamically.
- `src/database/database.module.ts` - global Postgres pool + Drizzle provider; closes the pool on shutdown.
- `src/database/schema.ts` - Drizzle schema (currently only the throwaway `health_check` table).
- `drizzle/` - SQL migrations generated by drizzle-kit (`NNNN_name.sql`) plus hand-written `NNNN_name.down.sql` rollbacks.
- `drizzle.config.ts` - drizzle-kit config. `pnpm --filter @fluxkit/api db:generate` creates a migration.
- `src/health/` - `GET /health`.
- `src/openapi-export.ts` - writes `docs/api/openapi.json` (run via `pnpm openapi:export`).
- `src/spikes/queue.spec.ts` - BullMQ spike against real Redis.
- `src/spikes/search.spec.ts` - Meilisearch spike (Ukrainian text, variant filters, facets); findings in `docs/adr/0005-search-notes.md`.
- `src/test/` - test helpers (`startApp`, `requireEnv`) and the fixture feature used by core tests.
- `vitest.config.ts` - Vitest with SWC (needed for Nest decorator metadata).
