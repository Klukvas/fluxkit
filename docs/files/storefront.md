# apps/storefront (Next.js App Router)

- `next.config.ts` - config as a function of the Next phase; redirects `/` to the default locale (literal, must match `defaultLocale` in `@fluxkit/ui`); rewrites `/store/:path*` to `${API_INTERNAL_URL}/store/:path*` in `next dev` ONLY (never in a build or `next start`; deployed environments use a reverse proxy, ADR 0026); `loadRootEnvFile` reads the root `.env` for `dev` and `start` (shell variables win). Imports `loadStorefrontEnv` from `@fluxkit/config` (a built package, so `pnpm build` once first). Must NOT contain page logic.
- `next.config.spec.ts` - Vitest unit tests of the phase gating, the rewrite target, the redirect and the `.env` loading (`pnpm --filter @fluxkit/storefront test`).
- `postcss.config.mjs` - Tailwind v4 PostCSS plugin.
- `src/app/globals.css` - imports Tailwind, design tokens and the token mapping; scans `packages/ui/src` for class names.
- `src/app/[locale]/layout.tsx` - `<html lang data-theme>`, metadata from i18n, 404 for unknown locales, static params for `uk` and `en`.
- `src/app/[locale]/page.tsx` - placeholder home page built only from `@fluxkit/ui` components, semantic classes and translated text.
- `src/messages/{uk,en}.json` - user-facing strings; `index.ts` maps locale to messages.
- `next-env.d.ts` - generated by Next, committed so a clean clone type-checks. `next dev` rewrites it to point at `.next/dev/types`; do not commit that change (run `git checkout apps/storefront/next-env.d.ts`).
- Run: `pnpm --filter @fluxkit/storefront dev -p 3001` (needs `pnpm build` once so workspace packages are built, and `API_INTERNAL_URL` in the root `.env` or the shell; the API on port 3000 with `STORE_COOKIE_SECURE=false`). Next telemetry is disabled in the scripts.
