# Public contracts

Everything listed here is covered by SemVer. Anything not listed is internal.

Files (create as the template grows):
- `api.md` - public storefront/admin API
- `slots.md` - UI slots and what can be injected
- `hooks-events.md` - hooks and events and their payloads
- `config.md` - feature flags and store settings schema
- `theme-tokens.md` - design tokens
- `db-extension.md` - tables/columns safe to extend

Entry format: name, since-version, description, shape, status (stable / deprecated since X).
